# MISPLACED — Alpha 0.1.1

Protótipo offline de terror top-down em pixel art.

## Build atual

- Escolha entre Sobrevivente e Monstro.
- Jogo 100% offline.
- Bots provisórios.
- Câmera suave.
- Colisão e portas.
- Escala interna 640×360 com pixel-perfect scaling.
- Sistema de visão por cômodos: áreas atrás de paredes ficam pretas e personagens nelas ficam invisíveis.
- Correção da máscara de escuridão para navegadores Android.

## Controles

**PC:** WASD/Setas para mover, Shift para correr, E para interagir, Esc para menu.

**Mobile:** analógico esquerdo para mover, RUN para correr e E para interagir.

Os personagens ainda usam arte procedural provisória enquanto fechamos escala, câmera, leitura visual e gameplay antes dos sprites definitivos.
